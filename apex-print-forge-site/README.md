# Apex Print Forge

This is a standalone static website. Upload these files to the root of a GitHub repository, then enable **GitHub Pages** under **Settings → Pages** (deploy from the `main` branch and `/root`).

Before publishing, update:

- `hello@apexprintforge.com` in `index.html`
- The Instagram and LinkedIn links in the footer
- The example project names and service wording, if needed

No installation or build step is required.
